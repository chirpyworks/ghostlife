# Security / private information

GHOSTLIFE's public repository must never contain private credentials, API secrets,
private infrastructure tokens, internal prompts, or unpublished commercial strategy.

If you believe sensitive information has been exposed:
1. do not repost it;
2. report the exact file/commit privately to the repository owner;
3. credentials will be rotated where applicable.

The public website intentionally contains public identifiers such as a GA4
Measurement ID. Public identifiers are not authentication secrets.
