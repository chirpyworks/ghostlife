# GHOSTLIFE

**당신이 지금의 삶을 살지 않았다면, 어떤 사람이 되었을까?**

GHOSTLIFE is an alternate-life identity experience: 8 scene-based choices, 16 unlived selves, and a shareable 9:16 result poster.

## Product

- 8 scene-based questions
- 16 deterministic archetypes
- balanced scoring architecture
- 1080×1920 PNG result poster export
- mobile file sharing
- direct result URLs
- friend comparison / dual timeline
- no login
- no paid API
- no database

https://chirpyworks.github.io/ghostlife/

## Status

Public v1 launch candidate.

GHOSTLIFE is an entertainment experience, not a psychological or personality diagnosis.
